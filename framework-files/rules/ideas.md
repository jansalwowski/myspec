# Ideas Management

The `${aiDir}/ideas/` directory contains raw feature ideas before they become formal specifications.

## Workflow

1. **New idea** → Follow `${aiDir}/ideas/INTAKE-INSTRUCTIONS.md` to analyze and queue
2. **Prioritize** → Check `${aiDir}/ideas/PRIORITY-LISTING.md` for priorities and dependencies
3. **Process** → Follow `${aiDir}/ideas/PROCESSING-INSTRUCTIONS.md` to create feature docs
4. **Complete** → Move idea to `${aiDir}/ideas/processed/`, update `PRIORITY-LISTING.md`

## Key Files

| File | Purpose |
|------|---------|
| `INTAKE-INSTRUCTIONS.md` | How to process new ideas into the queue |
| `PRIORITY-LISTING.md` | All ideas with priority and status |
| `PROCESSING-INSTRUCTIONS.md` | Convert ideas to feature docs |
| `processed/` | Completed ideas archive |

## When to Use

- **Adding a new idea**: Read `INTAKE-INSTRUCTIONS.md`, ask questions, add to queue
- **Checking what's next**: Read `PRIORITY-LISTING.md` for priorities
- **Converting idea to feature**: Follow `PROCESSING-INSTRUCTIONS.md` workflow
