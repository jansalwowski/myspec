# Dark Patterns — EU DSA Taxonomy

Load when audience = end-user (per dossier) OR surface is consent / sign-up / pricing / donate / nudge / marketing.

Per EU DSA Article 25: interfaces that mislead recipients or impair informed decisions are prohibited. Flag any of these for removal.

- **Urgency / scarcity** — countdown timers, "only 2 left", artificial deadlines. Acceptable only when factually true and verifiable.
- **Confirmshaming** — guilt-tripping the decline option ("No, I don't want to save money"). Use neutral wording on both choices ("Skip", "Maybe later").
- **Default-opt-in for sensitive actions** — marketing emails / data-sharing / notifications pre-checked. Sensitive consent defaults to off; the user opts in.
- **Visual-prominence bias on consent** — Accept large/coloured, Reject small/grey or hidden under a "More options" link. Both options must have equal weight.
- **Repetitive consent / nag prompts** — re-asking after a No within the same session or short window. Honour the user's No for a reasonable period.
- **Hidden costs / surprises** — fees, shipping, taxes revealed only at the final step. All material costs must be visible before the user commits.
- **Hard-to-find exits** — Close / Cancel / Unsubscribe buttons hidden, requiring extra clicks. The exit path is at least as findable as the commit path.
- **Disguised ads / sponsored content** — unmarked promotional content blended with organic. Sponsored must be visibly labelled.
- **Forced action** — locking the user out of unrelated functionality until they consent (cookie walls without a "reject all" of equal weight).
- **Trick wording / double negatives** — "Don't uncheck this box if you don't want emails." Plain affirmative wording only.

When flagging: cite the DSA category, propose the neutral replacement, and sweep every consent / sign-up / donation / pricing flow in the target feature against this list.
